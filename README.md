# استودیو نقاشی فندوقی 🌰🎨

وب‌اپ نقاشی و خلاقیت کودکان — فارسی، راست‌به‌چپ و کاملاً بدون نیاز به نصب.
ابزارهای حرفه‌ای، براش‌های جادویی، آلبوم شاهکارها و آموزش صفر تا صد ترفندهای نقاشی.

## ✨ امکانات

- 🖌️ **استودیوی نقاشی**: قلم‌مو، مداد، پاک‌کن، اسپری، سطل رنگ، خط، مستطیل، بیضی، مثلث و ستاره
- 🪄 **براش‌های جادویی**: رنگین‌کمان، برق جادویی، نئون درخشان و مهرهای قلب، ستاره، گل، پروانه و لبخند
- 🎨 **پالت رنگ**: ۱۲ رنگ آماده + رنگ دلخواه + تنظیم ضخامت قلم (۲ تا ۶۴)
- ↩️ **برگردان/دوباره** (Undo/Redo تا ۲۵ قدم) و میان‌برهای Ctrl+Z / Ctrl+Shift+Z
- 🖼️ **آلبوم شاهکارها**: ذخیره با نام دلخواه، نمایش بزرگ، دانلود PNG، ادامهٔ نقاشی و حذف
- 💾 **پیش‌نویس خودکار**: نقاشی نیمه‌کاره با رفرش صفحه از بین نمی‌رود
- 📚 **آموزش قدم‌به‌قدم**: ۵ آموزش تصویری (گربه، خانه، ماهی، درخت، پروانه) با نوار پیشرفت
- ✨ **ترفندهای طلایی**: ۶ ترفند برای راحت‌تر نقاشی‌کشیدن
- 🔊 **صداهای سرگرم‌کننده** (با دکمهٔ قطع/وصل)

## 🚀 اجرا

نیازی به نصب هیچ‌چیز نیست؛ یکی از این دو راه کافی است:

1. فایل `index.html` را مستقیم در مرورگر باز کنید.
2. یا با یک سرور استاتیک (توصیه‌شده):

```bash
cd Naqashi-Fandoqi
python3 -m http.server 8080
# سپس: http://localhost:8080
```

## 🧪 تست‌های خودکار

```bash
npm install        # فقط برای اجرای تست‌ها (jsdom، @napi-rs/canvas، pngjs)
npm test           # اجرای هر دو مجموعه
npm run test:unit  # تست‌های واحدی (منطق خالص، داده‌ها، ساختار فایل‌ها)
npm run test:e2e   # تست یکپارچه‌سازی (شبیه‌سازی مرورگر + رندر واقعی پیکسل‌ها)
```

تست واحد، سینتکس همهٔ ماژول‌ها، منطق هستهٔ ذخیره‌سازی، داده‌های آموزش و ساختار HTML/CSS را بررسی می‌کند.
تست یکپارچه، کل برنامه را در یک مرورگر شبیه‌سازی‌شده با رندر واقعی Canvas اجرا می‌کند: کشیدن با ابزارها،
Undo/Redo، سطل رنگ، براش‌های جادویی، ذخیره/نمایش/ادامه/حذف در آلبوم، آموزش گام‌به‌گام و میان‌برهای صفحه‌کلید.

## 🗂 ساختار پروژه

```
index.html          — صفحهٔ اصلی
css/style.css       — استایل‌ها (ریسپانسیو، RTL، دسترس‌پذیری)
js/storage-core.js  — هستهٔ ذخیره‌سازی (خالص، قابل تست)
js/utils.js         — ابزارهای عمومی
js/sound.js         — جلوه‌های صوتی Web Audio
js/engine.js        — موتور نقاشی (بوم، ابزارها، تاریخچه)
js/album.js         — آلبوم شاهکارها
js/tutorials.js     — آموزش‌ها و ترفندها
js/app.js           — اتصال ماژول‌ها و رابط کاربری
tests/checks.mjs    — تست‌های واحدی
tests/e2e.mjs       — تست یکپارچه‌سازی با رندر واقعی
docs/SPEC.md        — سند مشخصات پروژه
package.json        — اسکریپت‌های تست و اجرا
```

## 🛡 نکات فنی

- تمام داده‌ها فقط در `localStorage` مرورگر ذخیره می‌شوند (هیچ داده‌ای به سرور نمی‌رود).
- ورودی کاربر (نام نقاشی) با `textContent` رندر می‌شود تا خطر XSS وجود نداشته باشد.
- رکوردهای ذخیره‌شده هنگام خواندن اعتبارسنجی می‌شوند و سقف حجم آلبوم مدیریت می‌شود.
- بوم برای نمایشگرهای رتینا با نسبت پیکسل صحیح مقیاس می‌شود.
