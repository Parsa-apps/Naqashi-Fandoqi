# استودیو نقاشی فندوقی 🌰🎨 — آفلاین برای کودکان

وب‌اپ نقاشی و خلاقیت کودکان — فارسی، راست‌به‌چپ، **۱۰۰٪ آفلاین** و کاملاً بدون نیاز به نصب.
ابزارهای حرفه‌ای، براش‌های جادویی، آلبوم شاهکارها و آموزش صفر تا صد — حتی در هواپیما! ✈️📴

> **جدید در نسخه ۲.۰ آفلاین:** Service Worker + Manifest + فونت محلی + آیکون تولیدی — بدون اینترنت هم کار می‌کند!

## ✨ امکانات

- 🖌️ **استودیوی نقاشی**: قلم‌مو، مداد، پاک‌کن، اسپری (نقطه‌پاش واقعی!)، سطل رنگ، خط، مستطیل، بیضی، مثلث و ستاره
- 🪄 **براش‌های جادویی**: رنگین‌کمان، برق جادویی، نئون درخشان و مهرهای قلب، ستاره، گل، پروانه و لبخند
- 🎨 **پالت رنگ**: ۱۲ رنگ آماده + رنگ دلخواه + تنظیم ضخامت قلم (۲ تا ۶۴)
- ↩️ **برگردان/دوباره** (Undo/Redo تا ۲۵ قدم) و میان‌برهای Ctrl+Z / Ctrl+Shift+Z + [ و ]
- 🖼️ **آلبوم شاهکارها**: ذخیره با نام فارسی، نمایش بزرگ، دانلود PNG، ادامهٔ نقاشی و حذف — فقط localStorage
- 💾 **پیش‌نویس خودکار**: نقاشی نیمه‌کاره با رفرش صفحه از بین نمی‌رود
- 📚 **آموزش قدم‌به‌قدم**: ۵ آموزش تصویری (گربه، خانه، ماهی، درخت، پروانه) با نوار پیشرفت — آفلاین
- ✨ **ترفندهای طلایی**: ۶ ترفند + ۴ نکته آفلاین برای راحت‌تر نقاشی‌کشیدن
- 🔊 **صداهای سرگرم‌کننده** (با دکمهٔ قطع/وصل ذخیره‌شونده)
- 📴 **آفلاین کامل**: Service Worker Cache First، بدون CDN، فونت محلی، کار روی file://
- 📲 **قابل نصب**: PWA — دکمه «📲 نصب فندوقی» → مثل اپ واقعی روی موبایل/تبلت
- 💚 **امن برای کودک**: هیچ داده به سرور نمی‌رود، فقط textContent، مناسب مناطق کم‌برخوردار

## 🚀 اجرا — بدون اینترنت هم!

نیازی به نصب هیچ‌چیز نیست؛ یکی از این سه راه کافی است:

**راه ۱ — ساده (آفلاین محلی):**
```
فقط روی index.html دو بار کلیک کن!
حتی بدون سرور کار می‌کند 🎉
```

**راه ۲ — سرور محلی (توصیه‌شده برای PWA):**
```bash
cd Naqashi-Fandoqi
python3 -m http.server 8080
# سپس: http://localhost:8080
# حالا می‌تونی نصبش کنی!
```

**راه ۳ — USB برای مدارس روستا:**
```
کل پوشه را روی فلش بریز، بده به کودک — بدون اینترنت کار می‌کند!
```

### تست آفلاین بودن:
1. یک بار با اینترنت باز کن تا کش شود
2. اینترنت را قطع کن (یا DevTools → Offline)
3. رفرش کن — هنوز کار می‌کند؟ ✅ یعنی آفلاین آماده‌ست!

## 🧪 تست‌های خودکار

```bash
npm install        # فقط برای اجرای تست‌ها (jsdom، @napi-rs/canvas، pngjs)
npm test           # اجرای هر دو مجموعه ۱۰۸ تست سبز ✅
npm run test:unit  # تست‌های واحدی (منطق خالص، داده‌ها، ساختار فایل‌ها)
npm run test:e2e   # تست یکپارچه‌سازی (شبیه‌سازی مرورگر + رندر واقعی پیکسل‌ها)
```

تست واحد، سینتکس همهٔ ماژول‌ها (شامل sw.js و offline.js)، منطق هستهٔ ذخیره‌سازی، داده‌های آموزش و ساختار HTML/CSS را بررسی می‌کند.
تست یکپارچه، کل برنامه را در یک مرورگر شبیه‌سازی‌شده با رندر واقعی Canvas اجرا می‌کند: کشیدن با ابزارها، Undo/Redo، سطل رنگ، براش‌های جادویی، ذخیره/نمایش/ادامه/حذف در آلبوم، آموزش گام‌به‌گام و میان‌برهای صفحه‌کلید.

## 🛡 نکات فنی آفلاین

- **۱۰۰٪ آفلاین:** تمام داده‌ها فقط در `localStorage` + `CacheStorage` همین دستگاه — هیچ داده‌ای به اینترنت نمی‌رود.
- **بدون CDN:** قبلا Vazirmatn از cdn.jsdelivr.net می‌آمد — حالا `css/fonts.css` محلی با fallback هوشمند.
- **Service Worker:** Cache First — سریع‌ترین برای کودکان عجول. نسخه: `fandoqi-v2-offline-kids`.
- **امنیت:** ورودی کاربر (نام نقاشی) با `textContent` رندر می‌شود — ضد XSS. رکوردها با `validateRecord` پالایش می‌شوند.
- **حافظه:** سقف‌ها: آلبوم ۲۴ عدد، کل ۴.۵MB حروف JSON، اسنپشات تاریخچه ۲۴۰۰px، پیش‌نویس ۱۲۸۰px.
- **بوم:** مقیاس DPR سقف ۱.۵ برای رتینا، PointerEvents با setPointerCapture برای موس/لمس/قلم.
- **اسپری:** فقط نقطه می‌پاشد نه خط ممتد — باگ قبلی رفع شد!
- **PWA:** `beforeinstallprompt` → دکمه «📲 نصب فندوقی» + shortcuts (نقاشی/آلبوم/آموزش) + badge «💚 آفلاین».
