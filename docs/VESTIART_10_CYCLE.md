## چرا ۱۰ بخش؟

مغز کودک ۱۰ انگشت دارد! هر کار بزرگ را اگر به ۱۰ بخش تقسیم کنیم:
- هر بخش ۱۰٪ است — قابل فهم
- هر بخش خروجی ملموس دارد — قابل نمایش به کودک
- اگر یک بخش خراب شد، ۹ بخش دیگر سالم است — امن
- تست هر بخش فقط ۳ دقیقه — سریع

**این چرخه از گزارش ده‌بخشی مدیر فندوقی (REPORT.md) الهام گرفته و برای تمام پروژه‌های وستیارت تعمیم داده شده.**

## 🔄 چرخه کامل ۱۰ بخش — برای هر تسک

### بخش ۱: کشف و همدلی — بفهم قبل از اینکه بسازی 💚

**هدف:** بفهمی برای چه کسی می‌سازی؟ کودک ۴ ساله با انگشت بزرگ، یا ۱۰ ساله با موس؟

**چک‌لیست:**
- [ ] پرسونای کودک را بنویس: سن، دستگاه (تبلت/موبایل/دسکتاپ)، سطح سواد، اینترنت دارد یا نه؟
- [ ] نیاز اصلی را در یک جمله فارسی بنویس: «کودک می‌خواهد بدون اینترنت و بدون کمک مادر، ...»
- [ ] لیست FR (الزامات کارکردی) و NFR (غیرکارکردی: آفلاین، RTL، ریسپانسیو، امن) را بساز
- [ ] موارد مرزی را بنویس: اگر اینترنت قطع شد؟ اگر بوم خالی بود؟ اگر حافظه پر شد؟

**خروجی:** یک پاراگراف فارسی + جدول FR/NFR

**نمونه برای فندوقی:**
> FR-6: ذخیره آلبوم آفلاین با نام فارسی، ۲۴ عدد سقف، فقط localStorage

---

### بخش ۲: طراحی تجربه کودک — اول با مداد، بعد با کد 🎨

**هدف:** قبل از کدنویسی، روی کاغذ بکش.

**چک‌لیست:**
- [ ] وایرفریم با دست بکش: بوم کجاست؟ دکمه‌ها حداقل ۴۴px؟ رنگ‌ها شاد ولی نه جیغ؟
- [ ] سفر کاربر: ۳ کلیک تا شاهکار. بیشتر نشود!
- [ ] زبان: همه متن‌ها فارسی، راست‌به‌چپ، با اموجی تشویقی (🌈🎉) ولی نه زیاد
- [ ] دسترس‌پذیری: برچسب aria، فوکوس واضح، پشتیبانی لمس و موس
- [ ] قانون کودک: هیچ متن انگلیسی در UI نباشد

**خروجی:** اسکچ + لیست کامپوننت‌ها (header, toolbar, canvas-area, controlbar, modal)

---

### بخش ۳: معماری آفلاین — مثل خانه‌ات را قبل از اثاث بچین 🏠

**هدف:** تصمیم بگیر چه چیزی کجا ذخیره می‌شود و بدون اینترنت چگونه کار می‌کند.

**چک‌لیست:**
- [ ] استراتژی ذخیره: فقط localStorage / IndexedDB؟ هیچ بک‌اند نیست!
- [ ] Service Worker: Cache First برای کودکان (سریع‌ترین)
  - Precache فهرست: index.html, css/*, js/*, icons/*
  - Network Fallback: اگر نبود، index.html
- [ ] Manifest: name فارسی، icons 192 و 512، display standalone، theme #8a5cff
- [ ] فونت: هیچ CDN نباشد! fonts.css محلی + fallback سیستم
- [ ] آیکون‌ها: خودت تولید کن (canvas)، نه دانلود

**خروجی:**
- `sw.js` با CACHE_NAME نسخه‌دار
- `manifest.json`
- `css/fonts.css` بدون اینترنت
- `js/offline.js` ماژول مدیریت اتصال

**قانون طلایی آفلاین:**
```
اگر کاربر دو بار روی آیکون «نصب فندوقی» بزند، باید حتی در حالت هواپیما هم باز شود!
```

### بخش ۴: هسته‌های خالص — مغز را از بدن جدا کن 🧠

**هدف:** منطق را بدون DOM بنویس تا در Node هم تست شود.

**چک‌لیست:**
- [ ] `storage-core.js`: تمام کارهای حافظه، بدون window/document
  - `sanitizeName`, `validateRecord`, `canAdd`, `safeGet/Set`
  - سقف حجم و تعداد + پیام دوستانه
- [ ] `utils.js`: توابع خالص (clamp, hexToRgb, formatDateFa)
- [ ] هر تابع یک کار: کمتر از ۲۰ خط، نام واضح
- [ ] هیچ `innerHTML` با داده کاربر: فقط `textContent`

**خروجی:** ۲ فایل تست‌پذیر با `module.exports`

**تست:** در `checks.mjs` با حافظه ساختگی Map

### بخش ۵: موتور خلاقیت — جایی که جادو اتفاق می‌افتد ✨

**هدف:** موتور نقاشی: بوم، ابزارها، براش‌های جادویی

**چک‌لیست:**
- [ ] بوم: DPR حداکثر ۱.۵ برای رتینا، ResizeObserver برای تغییر سایز
- [ ] Pointer Events با setPointerCapture (موس + انگشت + قلم)
- [ ] تاریخچه: ۲۵ قدم، snapshot سقف ۲۴۰۰px برای حافظه
- [ ] ابزار حرفه‌ای (۱۰ عدد): brush, pencil, eraser, spray (فقط نقطه! نه خط ممتد), fill (flood fill با Uint8Array + tolerance), line, rect, ellipse, triangle, star
- [ ] براش جادویی (۸ عدد): rainbow (HSL hue), sparkle, glow (shadowBlur), stamp-* با destination-out
- [ ] صادرات: dataUrl با سقف ابعاد

**قانون طلایی کودکان:**
- پاک‌کن حداقل ۶px بزرگتر از قلم باشد — چون دست کودک می‌لرزد
- اسپری باید نقطه‌پاش باشد، نه خط‌کش!

**خروجی:** `js/engine.js`

**هدف:** ذخیره با نام فارسی، نمایش، دانلود، ادامه، حذف — همه آفلاین

**چک‌لیست:**

- [ ] حالت خالی با پیام تشویقی فارسی

- [ ] دانلود: فقط data:image معتبر

**خروجی:** `js/album.js`

### بخش ۹: تست مثل کودک شیطون — همه‌جا را خراب کن تا محکم شود 🧪

**هدف:** ۱۰۸ تست سبز قبل از تحویل

**ساختار تست ده‌بخشی:**
1. سینتکس همه JS (node --check)
2. storage-core با حافظه ساختگی
3. utils خالص
4. داده آموزش
5. ساختار HTML/CSS (lang=fa, dir=rtl, 3 تب)
6. E2E با jsdom + @napi-rs/canvas رندر واقعی پیکسل
7. ترسیم هر ابزار + رنگ
8. تاریخچه Undo/Redo + سطل رنگ + اسپری نقطه‌ای
9. آلبوم: ذخیره/نمایش/ادامه/حذف + امنیت textContent
10. آموزش + پیش‌نویس + Escape + صدا + [ و ]

**قانون تست کودک:**
> اگر تست پیکسل رنگین‌کمان، اشباع (saturation) را چک نکند، دروغ است! کودک رنگ را می‌بیند، نه کد را.

**خروجی:** `npm test` سبز + ۳ اجرای متوالی پایدار

## 🚀 قالب دستور برای وستیارت

هر بار که کاری به وستیارت می‌دهی، این قالب را بفرست:

```
تو وستیارت هستی — دستیار کودک‌محور آفلاین.

این کار را به ۱۰ بخش زیر تقسیم کن و هر بخش را کامل کن، بعد برو بخش بعد:

۱. کشف و همدلی: برای چه کودکی؟ چه سنی؟ چه دستگاهی؟ FR/NFR بنویس
۲. طراحی کودک: وایرفریم کاغذی، ۳ کلیک تا هدف، متن فارسی RTL
۳. معماری آفلاین: Service Worker Cache First + Manifest + fonts.css محلی + آیکون تولیدی
۴. هسته خالص: storage-core و utils بدون DOM، تست‌پذیر
۵. موتور خلاقیت: بوم DPR، Pointer Events، تاریخچه ۲۵، ابزارها + جادو
۶. آلبوم/داده: ذخیره امن textContent، thumbnail، حالت خالی مهربان
۷. آموزش/محتوا: داده ثابت SVG، پیشرفت localStorage
۸. ایمنی: فقط localStorage، sanitize، prefers-reduced-motion، صدای قابل قطع
۹. تست ده‌بخشی: unit + e2e با رندر پیکسل واقعی، ۳ بار پایدار
۱۰. مستند: README فارسی، اجرای بدون npm، چک آفلاین نهایی

قوانین طلایی:
- هیچ CDN نباشد — همه چیز آفلاین
- هیچ innerHTML با داده کاربر — فقط textContent
- دکمه‌ها ≥۴۴px — انگشت کودک بزرگ است!
- پیام‌ها فارسی کوتاه + اموجی، Toast
- هر بخش را که تمام کردی بگو «بخش X تمام ✅» و خروجی‌اش را نشان بده

شروع کن از بخش ۱ و لطفا الان فقط بخش ۱ را انجام بده و بپرس بریم بخش بعد؟
```

این قالب باعث می‌شود وستیارت هم مثل تو منظم، مهربان و آفلاین کار کند!

## 📴 چک‌لیست آفلاین نهایی — مخصوص کودکان

قبل از تحویل، این ۱۰ مورد را حتما چک کن:

- [ ] 1. اینترنت را قطع کن، صفحه را رفرش کن — آیا باز می‌شود؟
- [ ] 2. یک نقاشی بکش، ذخیره کن، اینترنت قطع، تب را ببند و باز کن — آیا در آلبوم هست؟
- [ ] 3. DevTools → Application → Cache Storage — آیا فایل‌هایت هست؟
- [ ] 4. Manifest در DevTools → Application → Manifest بدون خطا؟
- [ ] 5. Lighthouse → PWA → Installable و Offline سبز؟
- [ ] 6. موبایل: آیا «افزودن به صفحه اصلی» می‌آید؟
- [ ] 7. فایل‌ها روی file:// هم باز می‌شوند؟ (برای جاهایی که سرور نیست)
- [ ] 8. هیچ درخواست به cdn.jsdelivr.net یا گوگل فونت نیست؟ (Network tab)
- [ ] 9. آیکون آفلاین «💚 آفلاین» نمایش داده می‌شود؟
- [ ] 10. مادر یک کودک ۵ ساله می‌تواند بدون راهنما، نقاشی بکشد و ذخیره کند؟ (تست کاربر واقعی)

اگر هر ۱۰ تا ✅ شد، بگو: «فندوقی آفلاین آماده‌ست! 🌰💚»
