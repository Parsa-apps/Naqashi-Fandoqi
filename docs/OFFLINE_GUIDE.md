# راهنمای آفلاین فندوقی 🌰📴 — بدون اینترنت، پر از رنگ

> **این اپ ۱۰۰٪ آفلاین است — برای کودکان مناطق کم‌برخوردار، سفر، هواپیما، روستا**

---

## چگونه آفلاین کار می‌کند؟

### ۱. معماری سه‌لایه آفلاین

```
لایه ۱: فایل‌های استاتیک (HTML/CSS/JS/Icons)
  ↓ کش می‌شوند در
لایه ۲: Service Worker (sw.js) — Cache First
  ↓ ذخیره می‌شود در
لایه ۳: Cache Storage مرورگر + localStorage (نقاشی‌ها)
```

- **اولین بازدید:** همه فایل‌ها دانلود و در Cache Storage ذخیره می‌شوند
- **بازدیدهای بعدی:** حتی بدون اینترنت، از کش لود می‌شود — ۰.۳ ثانیه!
- **نقاشی‌ها:** فقط در localStorage همین دستگاه، هیچ جا ارسال نمی‌شود

### 2. فایل‌های کلیدی

| فایل | نقش آفلاین |
|------|------------|
| `manifest.json` | شناسنامه PWA — نام، آیکون، رنگ، shortcuts |
| `sw.js` | قلب آفلاین — Precache + Cache First + پاکسازی نسخه قدیمی |
| `css/fonts.css` | فونت محلی — بدون CDN، fallback به Tahoma |
| `js/offline.js` | مدیر مهربان — تشخیص آنلاین/آفلاین، badge، نصب |
| `icons/*.png` | آیکون‌های تولیدی با canvas — بدون دانلود |

### ۳. استراتژی Cache First — چرا برای کودک بهتر است؟

- **Network First:** کودک باید منتظر اینترنت بماند → بد
- **Cache First:** فوری از کش می‌دهد، در پس‌زمینه آپدیت → عالی برای کودک عجول

```js
// ساده‌شده:
caches.match(req).then(cached => {
  if (cached) return cached; // فوری
  return fetch(req).then(r => cache.put(req, r)); // بعد کش کن
});
```

- [x] حذف `preconnect` — هیچ درخواست خارجی نیست

- [x] تمام JS/CSS لوکال
- [x] حتی `file://` کار می‌کند (بدون SW)

### ۵. تجربه کودک در آفلاین

- **Badge:** «💚 آفلاین» همیشه بالا — کودک می‌فهمد حتی بدون اینترنت کار می‌کند
- **Toast آفلاین:**
  - قطع شد: «📴 اینترنت قطع شد؟ مهم نیست! نقاشیت رو ادامه بده 🎨»
  - وصل شد: «🌐 دوباره آنلاینی! ولی فندوقی همیشه آفلاین هم کار می‌کنه 😉»
- **نصب PWA:** دکمه «📲 نصب فندوقی» → مثل اپ واقعی، در هواپیما هم

### ۶. تست آفلاین — ۱۰ قدم

1. `python3 -m http.server 8080`
2. باز کن `http://localhost:8080`
3. یک نقاشی بکش و ذخیره کن
4. DevTools → Application → Service Workers → Offline را تیک بزن
5. رفرش → آیا باز می‌شود؟
6. آیا نقاشی در آلبوم هست؟
7. Network tab → آیا هیچ درخواستی fail نیست جز آفلاین؟
8. Lighthouse → PWA → ۱۰۰٪؟
9. موبایل: Add to Home Screen
10. حالت هواپیما → باز کن → کار می‌کند؟

### ۷. به‌روزرسانی نسخه

در `sw.js`:
```js
const CACHE_NAME = 'fandoqi-v2-offline-kids';
```
هر تغییر بزرگ → نسخه را `v3` کن → کاربر قدیمی کش قدیمی را حذف می‌کند.

### ۸. محدودیت‌های آفلاین (و راه حل کودک‌پسند)

| محدودیت | راه حل |
|---------|--------|
| حافظه مرورگر پر | Toast: «آلبوم پر است! چند نقاشی قدیمی را حذف کن 🗑️» |
| file:// SW کار نمی‌کند | offline.js حالت `offline-local` با badge جدا |
| فونت Vazirmatn نیست | fallback به Tahoma — هنوز خواناست |

### ۹. امنیت کودکان — آفلاین امن‌تر است

- هیچ داده به اینترنت نمی‌رود → والدین خوشحال
- `textContent` فقط → ضد XSS
- `safeGet/Set` در try/catch → حالت ناشناس مرورگر خراب نمی‌کند

### ۱۰. چرا این برای ایران مهم است؟

- روستاها اینترنت ضعیف
- تبلت مدارس بدون سیم‌کارت
- هواپیما/سفر جاده‌ای
- والدین که نمی‌خواهند کودک آنلاین باشد

> **فندوقی: حتی تهِ جنگل هم کار می‌کند، اگر یک بار لود شده باشد 🌲🌰**
