## 📦 فایل‌های APK / AAB

```
نام فایل:        naqashi-fandoqi-v2-1-release.apk    (یا)
                  naqashi-fandoqi-v2-1-release.aab
حجم تقریبی:      ۲ تا ۳ مگابایت
minSdk:           ۲۱ (Android 5.0)
targetSdk:        ۳۴ (Android 14)
امضا:            با keystore اختصاصی (نه debug.keystore)
```

نحوهٔ ساخت Release APK (در Android Studio):
1. `Build → Generate Signed Bundle / APK`
2. گزینهٔ `APK` یا `Android App Bundle` را انتخاب کن
3. کلید امضا را بساز (یک‌بار برای همیشه نگه دار، گم نکن!)
4. `release` را انتخاب کن (نه debug)
5. منتظر بمان
6. فایل نهایی در `android/app/build/outputs/apk/release/` یا `bundle/release/`

نحوهٔ ساخت Release APK (در خط فرمان با keystore موجود):
```bash
cd android
./gradlew assembleRelease
# خروجی: app/build/outputs/apk/release/app-release.apk
```
