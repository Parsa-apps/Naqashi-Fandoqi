# فندوقی — فایل APK آماده نصب 📱🌰

این پوشه شامل فایل APK آماده برای نصب روی **همه گوشی‌های اندروید ۵ به بالا (API 21+)** است.

## 📦 فایل‌ها

- `fandoqi-debug.apk` — نسخه دیباگ، آماده نصب مستقیم (۱.۳ مگابایت)
- `fandoqi.apk` — کپی همین فایل در ریشه پروژه برای دسترسی آسان

## 📲 نصب — ۳۰ ثانیه

1. فایل `fandoqi-debug.apk` را به گوشی بفرست (تلگرام، واتساپ، کابل USB...)
2. روی فایل بزن
3. اگر گوشی گفت **"نصب از منابع ناشناس"** → برو تنظیمات → اجازه بده → برگرد نصب کن (طبیعی است چون از گوگل‌پلی نیست)
4. تمام! آیکون 🌰 فندوقی روی صفحه می‌آید
5. **حالت هواپیما را روشن کن و بازش کن — بدون اینترنت هم کار می‌کند!** 📴

## 🔍 مشخصات APK

- **Package:** `com.quadrats.eriatnotpersonalapp` (نسخه آزمایشی) → نسخه اصلی `com.fandoqi.app` در پروژه اندروید
- **minSdk:** 21 — اندروید ۵ (Lollipop) تا اندروید ۱۴+
- **حجم:** ~۱.۳ مگابایت (خیلی سبک!)
- **آفلاین:** ۱۰۰٪ — تمام فایل‌ها داخل APK هستند
- **امن:** هیچ داده به اینترنت نمی‌فرستد

> **نکته:** این APK با وصله (patch) یک WebView ساده ساخته شده تا روی همه گوشی‌ها نصب شود.
> برای نسخه اصلی با package `com.fandoqi.app` و آیکون اختصاصی، پروژه `android/` را در Android Studio باز کن و Build APK بزن — همان فایل ولی با نام و آیکون فندوقی اصلی.

## 🛠️ ساخت نسخه اصلی (توصیه‌شده)

اگر می‌خواهی APK با نام و آیکون اصلی فندوقی بسازی:

```bash
# راه ۱: Android Studio — ۱ کلیک
File → Open → پوشه android → Build → Build APK(s)

# راه ۲: خط فرمان
./build-apk.sh

# خروجی:
# android/app/build/outputs/apk/debug/app-debug.apk
```

راهنمای کامل: `docs/APK_GUIDE.md` و `android/README.md`

## ❓ چرا دوتا APK؟

- `apk/fandoqi-debug.apk` — نسخه سریع و آماده که همین الان با همین ابزار ساخته شد (برای تست فوری)
- `android/app/build/.../app-debug.apk` — نسخه اصلی که خودت با Android Studio می‌سازی (توصیه‌شده برای انتشار)

هر دو روی همه گوشی‌ها نصب می‌شوند و آفلاین کار می‌کنند!

## 🌰 برای بچه‌ها

این APK را بریز روی یک فلش، بده به معلم روستا — روی تبلت‌ها نصب می‌کند، بدون اینترنت نقاشی می‌کشند، شاهکارها در خود تبلت می‌ماند 💚
