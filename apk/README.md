# فندوقی — فایل APK آماده نصب 📱🌰

این پوشه شامل فایل APK آماده برای نصب روی **همه گوشی‌های اندروید ۵ به بالا (API 21+)** است.

## 📦 فایل‌ها

- `fandoqi-debug.apk` — نسخه دیباگ (در ریشه پروژه، `fandoqi.apk` نسخه release با امضای دیباگ است)
- هر دو فایل **به صورت خودکار توسط GitHub Actions** در هر پوش از نو ساخته می‌شوند
  (ورک‌فلو: `.github/workflows/Apk.yml`) و داخل ریپو commit می‌شوند — یعنی همیشه هم‌نسخه با آخرین کد هستند.

## 📲 نصب — ۳۰ ثانیه

1. فایل APK را به گوشی بفرست (تلگرام، واتساپ، کابل USB...)
2. روی فایل بزن
3. اگر گوشی گفت **«نصب از منابع ناشناس»** → برو تنظیمات → اجازه بده → برگرد نصب کن (طبیعی است چون از گوگل‌پلی نیست)
4. تمام! آیکون 🌰 فندوقی روی صفحه می‌آید
5. **حالت هواپیما را روشن کن و بازش کن — بدون اینترنت هم کار می‌کند!** 📴

> ⚠️ **اگر قبلاً نسخه قدیمی نصب کرده‌ای:** اول نسخه قبلی را **حذف** کن بعد این را نصب کن.
> نسخه‌های خیلی قدیمی با پکیج `com.quadrats...` بودند و جدید با `com.fandoqi.app` — نصب کنار هم ممکن
> است ولی باعث دوتا آیکون می‌شود. در تنظیمات → Apps می‌توانی نسخه نصب‌شده را ببینی (باید `2.1.0` باشد).

## 🔍 مشخصات APK

- **Package:** `com.fandoqi.app`
- **minSdk:** 21 — اندروید ۵ (Lollipop) تا جدیدترین
- **حجم:** حدود ۱.۵ مگابایت — چون اپ یک WebView سبک با **صفر وابستگی خارجی** است و کل
  کد (HTML/CSS/JS متنی) داخل APK به‌شدت فشرده می‌شود. حجم کم = سالم بودن، نه کم‌کاری! 🌰
- **آفلاین:** ۱۰۰٪ — تمام فایل‌ها داخل APK هستند
- **امن:** هیچ داده به اینترنت نمی‌فرستد

## 🛠️ ساخت دستی (اختیاری)

APKها خودکار ساخته می‌شوند، ولی اگر خواستی دستی بسازی:

```bash
# راه ۱: Android Studio — ۱ کلیک
File → Open → پوشه android → Build → Build APK(s)

# راه ۲: خط فرمان
./build-apk.sh

# خروجی علاوه بر پوشه build، در این مسیرها هم به‌روز می‌شود:
#   fandoqi.apk  و  apk/fandoqi-debug.apk
```

راهنمای کامل: `docs/APK_GUIDE.md` و `android/README.md`

## 🤖 ساخت خودکار (GitHub Actions)

- در هر پوش روی `main` یا برنچ‌های `arena/*`، ورک‌فلو `📱 Build Fandoqi APK` اجرا می‌شود:
  1. فایل‌های وب (index.html, css/, js/, icons/, sw.js, manifest.json) را داخل پروژه اندروید سینک می‌کند
  2. با Gradle نسخه debug و release می‌سازد
  3. `fandoqi.apk` و `apk/fandoqi-debug.apk` را در ریپو به‌روز و commit می‌کند
  4. APKها را به‌عنوان artifact هم آپلود می‌کند (تب Actions ← آخرین اجرا ← Artifacts)
